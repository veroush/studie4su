## Inleiding / Introduction

Studie4SU is a comprehensive web application designed to help Surinamese students navigate their educational options. The platform allows users to explore various schools, attend virtual open houses, review academic programs, and utilize an interactive quiz to aid in their decision-making process.

## Technical Architecture

The application is currently undergoing a structural modernization to improve performance, scalability, and maintainability. The updated architecture consists of three main pillars:

*   **Frontend (User Interface):** Built with **TanStack Start UI** and styled using **Tailwind CSS**. This ensures a highly responsive and fast user experience across desktop and mobile devices.
*   **Backend (API Layer):** Powered by **Hono**, replacing the legacy Express.js framework to provide a faster, more lightweight routing system for our endpoints (`/schools`, `/users`, `/auth`).
*   **Database & Authentication:** Managed via **PostgreSQL** and accessed through **Prisma ORM**. Authentication flows and route protection are handled securely by **Better Auth**.
