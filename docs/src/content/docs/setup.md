## Running the Documentation Site (Local)

The documentation site is built using Astro (Starlight). To view or edit these documents locally, follow these steps:

1. Clone the repository and navigate to the `docs` directory:
   \`\`\`bash
   cd docs
   \`\`\`
2. Install the necessary dependencies:
   \`\`\`bash
   pnpm install
   \`\`\`
3. Start the local development server:
   \`\`\`bash
   pnpm run dev
   \`\`\`
4. Open your browser and navigate to `http://localhost:4321`.
